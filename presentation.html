Problem Statement

⚠️ Why Current Surveillance Systems Fail

🔴 Passive Recording

CCTV records events but cannot trigger real-time alerts. Threats are discovered only after harm occurs — too late for intervention.

🔴 Human Fatigue

Studies show operators miss up to 45% of events after 20 minutes. Large deployments make continuous monitoring humanly impossible.

🔴 Single-Dimension Detection

Existing AI systems detect either suspicious actions OR physical objects — never both — leaving critical blind spots.

✅ Our Proposed Solution

An autonomous dual-model pipeline: DSANet for temporal behavior analysis across 14 crime categories + YOLOv8 for instant weapon spotting, with automated forensic logging to a searchable database — converting passive CCTV into an active defense layer.

Segment 1

🎬 Preprocessing & Feature Extraction

1. Frame Skipping (skip=3)

Only every 3rd frame enters the pipeline, cutting compute by 66% while preserving enough temporal resolution for action understanding. Non-inference frames still stream to the UI.

2. CLIP ViT-B/16 Encoding

OpenAI's CLIP vision transformer converts each BGR frame → RGB PIL image → preprocessed tensor → 512-dim L2-normalized embedding. This semantic representation is rotation, brightness, and style invariant.

3. Temporal Rolling Buffer

A deque(maxlen=32) accumulates embeddings. When full, it provides DSANet with ~3 seconds of temporal context — essential for detecting actions that evolve over time.

# Skip non-inference frames
if frame_count % skip != 0:
    _encode_frame(frame, score, label, is_anomaly)

# CLIP encodes to 512-dim embedding
with torch.no_grad():
    feat = clip_model.encode_image(inp)
    feat = feat / feat.norm(dim=-1, keepdim=True)

# Append to rolling buffer
buffer.append(feat.cpu().numpy())

Segment 2

🧠 Anomaly Detection — DSANet

Temporal Transformer

Windowed self-attention (window=attn_window) across 32 CLIP embeddings. Learns which frame intervals are causally linked to anomalous behavior without requiring frame-level labels.

Dual-Branch GCN

Adjacency Branch (gc1/gc2): Builds graph from cosine similarity between features.
Distance Branch (gc3/gc4): Uses temporal distance as edge weight. Both branches concatenated → linear projection.

Hierarchical Score Refinement

Binary MLP score (is it abnormal?) × text-aligned class distribution (which crime?) → fine-grained per-class anomaly probabilities. Anomaly score = 1 − P(normal)

run_pipeline_live.py — score refinement
def refine_scores_hierarchical(l_mlp, l_align, temp=5.0):
    # Step 1: binary is-it-abnormal prob
    p_abn  = torch.sigmoid(l_mlp / temp)
    p_norm = 1.0 - p_abn

    # Step 2: CLIP text-aligned distribution
    p_align  = F.softmax(l_align / temp, dim=1)
    p_crimes = p_align[:, 1:]  # drop "normal"
    dist = p_crimes / (p_crimes.sum(dim=1,
                      keepdim=True) + 1e-12)

    # Step 3: multiply → fine-grained scores
    probs = torch.cat([p_norm, p_abn * dist], dim=1)
    return probs

score = (1 - probs[:, 0]).max().item()
label = "CRIME DETECTED" if score > 0.45 else "NORMAL"

Segment 3

🎯 Weapon Detection — YOLOv8

Specialist Firearm Model

best.pt is fine-tuned exclusively on firearm imagery, not a generic COCO model. Every class it predicts is a weapon category — enabling high-confidence gun detection even in low-quality CCTV footage.

Inference Settings

imgsz=320 for real-time speed · conf=0.40 for precision–recall balance · half=True on CUDA for 2× speedup · Verbose=False to suppress console spam.

Dual Trigger Architecture

A danger event fires if either condition is true:
• DSANet anomaly score > 0.45
• YOLOv8 detects any weapon
This covers "calm" scenarios where a weapon appears before violence starts.

🗄️ Forensics — Storage & Classification

HuggingFace Crime Classifier

Model: dima806/crime_type_cctv_image_detection
Lazy-loaded on first danger event (singleton pattern with threading lock). Runs as a background daemon thread on the captured JPEG snapshot to avoid blocking the main detection loop.

Rate-Limited DB Writes

Writes throttled to 1 event per second using time.time() comparison — prevents storage flooding during sustained incidents while still capturing the key moment.

def save_danger_frame(score, label, dtype,
                       weapons, frame_bgr):
    # 1. HF classifier (lazy singleton)
    clf  = _get_hf_classifier()
    pil  = Image.fromarray(
               cv2.cvtColor(frame_bgr, BGR2RGB))
    pred = clf(pil)
    crime_type = pred[0]["label"]

    # 2. Encode frame as 80% quality JPEG
    _, buf = cv2.imencode(".jpg", frame_bgr,
                     [IMWRITE_JPEG_QUALITY, 80])
    ts = time.strftime("%Y-%m-%d %H:%M:%S")

    # 3. Insert all fields into SQLite
    con.execute("INSERT INTO danger_events "
                "VALUES (?,?,?,?,?,?,?,?)",
        (ts, score, label, dtype,
         json.dumps(weapons), buf, crime_type))
    con.commit()

② DSANet Inference (main.py)
def infer_buffer(model, feats,
                  prompt, args, dev):
    # Stack buffer → tensor
    vis = torch.tensor(feats)
           .unsqueeze(0).float().to(dev)
    L   = vis.shape[1]

    # Build padding mask
    lens = torch.tensor([L])
    mask = get_batch_mask(lens,
                args.visual_length).to(dev)

    # Forward pass
    _, l1, l2, _, _ = model(
        vis, mask, prompt, lens, False)
    l1 = l1.reshape(-1, l1.shape[-1])
    l2 = l2.reshape(-1, l2.shape[-1])

    probs = refine_scores(l1, l2, args.temp)
    return (1 - probs[:,0]).max().item()
